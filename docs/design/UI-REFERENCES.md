# 대화형 UI 참고 조사

- 조사: 2026-11-05. 감좋은청년의 화면 구성 참고용이며 기능 구현·효과 검증 자료가 아니다.

## 참고와 적용

| 공식 자료 | 확인한 방향 | 감좋은청년의 디자인 판단 |
|---|---|---|
| [Intercom — Conversational Fin experience](https://www.intercom.com/help/en/articles/11433030-conversational-fin-experience) | 자연스러운 짧은 응답, 문맥을 이어가는 대화, 고정 빠른 답변 흐름 축소 | 선택 버튼 나열을 줄이고 사용자 문장→짧은 답변→필요한 행동으로 구성 |
| [Intercom — Updates to the Messenger](https://www.intercom.com/help/en/articles/9319961-updates-to-the-messenger) | 대화 직접 진입, 단순한 헤더, 읽기 쉬운 답변 영역 | 하단 다중 탭 제거 유지, 입력창 고정, 금액·일정 카드만 구조화 |
| [Google Material Web — Chips](https://github.com/material-components/material-web/blob/main/docs/components/chip.md) | assist·suggestion 등 짧은 행동과 제안의 구분 | 처음 시작할 때의 질문 제안과 실행·승인 버튼의 위계를 분리 |

위 적용은 자료를 그대로 복제한 것이 아니라 제품 과제에 맞춘 디자인 판단이다. 경쟁사의 UI가 우리 제품의 생산성 효과를 입증하지는 않는다.

## 시각 조사 범위와 제외

Cleo 및 Intercom의 대화 화면도 이미지 검색으로 참고했다. Cleo의 과거 공식 블로그 링크는 본문 조회에서 410 Gone으로 확인되어 현재 기능·설계의 근거로 사용하지 않았다. 외부 스크린샷이나 전체 UI 이미지를 Figma 결과물에 넣지 않았다. 감 심볼은 이번 제품에 맞춰 직접 작성한 편집 가능한 SVG다.

## 수정한 문제

- 같은 대형 버튼이 조회·복사·등록에 반복되던 문제: 아이콘·폭·위치로 행동을 구분한다. 사용자 최종 요청에 따라 색은 모두 주황으로 유지하고 높이 44px, 모서리 12px, 라벨 13px Medium으로 정리했다.
- AI 이름과 카드가 반복되며 폼처럼 보이던 문제: 사용자 말풍선과 AI 본문을 구분하고 라벨 반복 축소.
- 추상적인 인사말: 월세·전기요금이 드러나는 구체적인 문구로 교체.
- 임시 사각형 심볼·텍스트 상태 아이콘: 감 모양과 일관된 선 아이콘으로 교체.
- 카드가 입력창에 가까워지는 문제: 전체 상태의 대화 하단 좌표 검증.

## 제한

현재는 고정된 상태를 연결한 디자인 프로토타입이다. 금융 연결·납부·복사는 실제 실행하지 않는다. 공용 버튼 라이브러리 가져오기가 이전 작업에서 응답 크기 제한으로 실패하여 이번 시안은 편집 가능한 프레임·텍스트·벡터를 사용했다. 라이브러리 컴포넌트화는 미완료다.
