# 전기·도시가스 연동 사전 조사

- 조사일: 2026-11-05 (Asia/Seoul)
- 관련 피처: F01. 상태: 후보와 공개 근거 확보, 실호출·이용승인 미검증.
- 범위: 개인별 청구금액·납부기한·납부 확인을 가져올 수 있는 경로. 사용량 통계 API와 구분.

## 최신 MVP 적용 범위

사용자 결정에 따라 3명·120분 MVP에서는 **한전만 외부 연동**한다. 가스 관련 내용은 후속 검토 자료다. 월세는 API·계약서 없이 직접 등록해 송금 안내 텍스트만 제공한다. 15분까지 한전 접근을 판정하고 막히면 합성 샘플 모드로 전환한다. 기존 조사상의 여러 공급기관 비교·이메일 수집은 이번 필수 구현이 아니다. 문서 조사만으로 F01이 완료된 것은 아니다.

## 결론

연동 후보가 있다. 한전 공식 EDS의 청구정보 서비스 목록과 민간 사업자의 청구 조회 API를 확인했다. 단, API 상품 존재와 우리 팀의 실제 이용 가능 여부는 다르다. 계정 생성, 유료 결제, 문의 발송 및 개인정보 조회는 수행하지 않았다.

## 확인한 후보

| 경로 | 확인된 제공 범위 | 남은 검증 |
|---|---|---|
| 한전 공식 EDS | 공식 API 목록에 고객정보·고객번호·청구정보 존재 | 사업자 등록·이용승인·동의 절차, 개인/주택 지원, 납부기한·상태 필드, 비용, 인증 갱신 |
| 하이픈 한국전력 청구/납부 조회 | 스크래핑 API 상품. 청구월·청구요금·납부방법·사용량·미납내역 및 납부내역 | 납부기한 응답 필드, 인증 방식, 실제 계정 테스트, 반복 조회 가능성 |
| 하이픈 도시가스 청구 조회 | 스크래핑 API 상품. 청구금액·납부 마감일·사용량·납부방법 | 지원 가스사 목록, 영남에너지서비스(구미) 지원, 인증·동의, 납부 완료 조회 가능성 |
| 인포텍 공과금조회 | 한국전력 전기료 및 서울·경기 도시가스 조회 안내. 로컬/서버 스크래핑·Cloud API | 지원 가스사, 테스트 제공, 입력/출력 명세, 계약·요금 |

한전 EDS의 공공데이터포털 페이지는 **API 서비스의 목록 데이터**다. 해당 목록 조회용 odcloud API 키가 개인 청구정보 조회 권한을 주는 것은 아니다. 목록 페이지의 무료 표기도 실제 EDS 청구 조회의 비용으로 해석하지 않는다. EDS 사이트 본문은 이번 웹 도구에서 접근되지 않아 이용절차를 확인하지 못했다.

하이픈 두 상품 페이지에는 TR슬림 월 멤버십 10만 원과 건별 과금, 테스트베드 제공이 안내된다. 실제 적용 요금·부가세·테스트가 합성인지 실데이터인지·개인 개발자 이용 가능 여부는 확인이 필요하다. 가입이나 결제를 진행하지 않았다.

## 청도 지역 가스

영남에너지서비스(구미)의 공식 회사 소개는 청도를 공급지역에 포함한다. 도시가스 대상 사용자는 우선 해당 공급사의 지원 여부를 검증해야 한다. 지역 전체가 공급 대상이라는 뜻은 아니므로 사용자 고지서의 실제 공급사를 확인한다. LPG·집주인 정산·관리비 합산 건도 별도 경로로 다뤄야 한다는 것은 제품 설계상 확인할 가설이다.

## 우리 제품에 적용할 방향

- 공식 EDS와 하이픈의 이용 가능성을 우선 비교한다. 아직 업체를 확정하지 않는다.
- 한전은 청구액뿐 아니라 납부기한을 반드시 확인한다. 납부일자(결제된 날짜)와 납부기한(앞으로 낼 날짜)을 혼동하지 않는다.
- 가스는 대상 공급사 1곳을 먼저 확정한다. '전국 도시가스 지원'으로 표현하지 않는다.
- 정기 조회에 매번 본인인증이 필요한지 확인한다. 최초 연결만으로 무기한 자동 수집이 된다고 약속하지 않는다.
- 조회 API가 있어도 새 고지서 도착 웹훅이 있는지는 별도다. 웹훅 미지원이면 허용된 호출량 내 정기 조회를 설계한다.
- 확인된 납부기한을 저장한 후 알림 예약은 앱이 자체 수행할 수 있다.
- 조회 지원과 실제 납부/결제 지원을 구분한다. 이 조사에서 실제 결제 연동은 검증하지 않았다.

## 다음 검증 체크리스트

1. 개발팀/개인 계정으로 이용 가능한지, 승인 소요와 비용·테스트 범위 확인.
2. 동의한 테스트 사용자의 고객번호/공급계약 연결 가능 여부 확인.
3. 청구월·금액·납부기한·자동이체·납부상태의 응답 샘플 확인.
4. 인증 재요청·동의 철회·명의 불일치·공급사 미지원 처리 확인.
5. 주기적 갱신 허용, 호출 한도, 장애/실패 코드 확인.
6. 최소 한 건을 실제 고지서와 대조한 뒤 실연동 가능으로 판정.
