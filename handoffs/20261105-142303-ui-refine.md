## 완료와 변경

사용자 요청에 따라 서비스명을 감좋은청년으로 바꾸고 월세 일정·계좌 직접 등록, 한전 연결을 중심으로 대화 UI를 재구성했다. Intercom과 Google Material의 공식 자료를 조사하고 사용자 말풍선, 짧은 AI 응답, 금융 정보 카드, 고정 입력창을 정리했다. 감 모양 SVG 심볼과 모바일 상태·행동 아이콘, 자연스러운 한국어 문구를 추가했다.

최종 요청은 모든 행동 버튼 색을 주황색으로 통일하는 것이다. 검정 버튼·중립 버튼으로 나눴던 중간안은 폐기했다. 주황 #FF7A1A, 검정 라벨, 높이 44px, 모서리 12px, 13px Medium / 20px 줄 높이, 아이콘 간격 7px를 적용했다. 전송은 주황 원형이다. 색이 아닌 폭·위치·아이콘으로 위계를 구분한다.

## 검증

- 주요 채팅·등록·조회·복사·연결·캘린더·오류·완료 화면의 Figma 캡처를 확인했다. 캘린더 화살표 줄바꿈, 버튼과 정보 카드의 동명 처리 오류를 수정했다.
- 모든 대화 상태의 하단 좌표를 검사했으며 입력 영역 시작 y=701을 넘는 항목은 0개였다.
- 19개 행동 버튼과 전송 버튼의 주황색 적용 결과를 캡처로 확인했다.
- 문서 UTF-8·로컬 링크·공백 검사는 종료 전 실행 출력으로 확인한다.
- 앱 실행, 실제 클립보드 복사, 한전 인증/조회, 납부, 알림 발송, 키보드·스크린리더, 반응형은 검증하지 않았다.

## 알려진 제한

- 고정 상태를 연결한 디자인 프로토타입이며 임의의 자연어를 실제로 처리하지 않는다.
- 한전 연결은 검증 전이다. 샘플 체험→샘플 조회, 연결 시도→연결 확인 실패로 연결해 실연동을 가장하지 않는다.
- 초기 알림 동의의 상세 화면, 시작월 확인 세부 상태는 후속 설계가 필요하다. 월세 등록과 반복 알림의 데이터 계약은 최신 TRD를 따른다.
- 월세 '납부했어요' 이후의 월세 전용 확인 상태는 미연결이다. 전기요금의 사용자 확인 전후 상태를 대표로 디자인했다.
- 버튼 아이콘·형태는 편집 가능한 프레임·벡터·텍스트이며 공용 컴포넌트 라이브러리화는 미완료다.
- Figma 내부 화면의 이름은 교체했으나 파일 자체의 제목 변경은 별도로 검증하지 않았다.
