## 완료와 변경

`research/electricity-payment-options.md` 생성. NH 공과금 납부 API, 오픈지로, 인포텍, 송금대행과 공식 납부 페이지 연결을 비교했다. 사용자는 조사 중 '금액 조회와 페이지 연결도 괜찮다'고 확정했다. 이는 기존 PRD의 실제 결제 제외 범위와 일치해 핵심 기획 파일은 수정하지 않았다.

## 발견한 문제

NH는 납부까지 명시한 API와 과거 공개 명세가 있으나 개발자센터 링크는 2025-12-31 종료 안내로 연결된다. 현행 신규 이용·키 발급·테스트 접근은 확인하지 못했다. 과거 명세의 납부기한 필드는 발견했지만 실제 호출·현행 지원을 검증하지 않았다.

## 검증

공식 서비스 소개, 공개 명세, 개발자센터 종료 안내, 정식 이용절차를 웹으로 확인했다. 계정 생성·문의 발송·유료 결제·개인정보 조회·실송금은 하지 않았다. 로컬 문서 공백/UTF-8 검사는 종료 전 수행한다. 앱 기능 테스트는 미실행.

## 다음 순서

1. 금액·납부기한을 제공할 조회 경로를 확보한다. 막히면 샘플 표시.
2. 한전ON 공식 납부 링크를 실제 브라우저에서 확인하고 버튼에 연결한다.
3. 링크 방문과 납부 완료를 분리하고 사용자 납부 확인 후 알림을 중지한다.
4. 자동 입력 링크·완료 콜백은 확인 전 구현됐다고 표현하지 않는다.
