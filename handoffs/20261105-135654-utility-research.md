## 완료와 변경

`research/utility-integrations.md`에 한전 EDS, 하이픈 전기·가스, 인포텍 후보와 공식 근거, 청도 가스 공급사, 후속 검증 순서를 기록했다. 기존 PRD/TRD/TDD 및 API 계약은 변경하지 않았다.

## 핵심 결정과 제한

- EDS 공식 목록에 청구정보가 있다. 목록의 API와 개인 청구정보 조회 API를 혼동하지 않는다.
- 하이픈은 전기·가스 스크래핑 API 상품을 공개한다. 유료이며 테스트·인증·공급사 범위 확인 필요.
- 청도는 영남에너지서비스(구미) 공식 공급현황에 포함. 해당 업체 지원 여부는 아직 미확인.
- 상품을 찾았다는 이유로 실제 연결 완료라고 표현하지 않는다.

## 검증

- 제공기관 및 API 업체의 공개 웹페이지 조사. 한전 EDS 본문 직접 접근은 웹 도구에서 실패.
- 실제 가입·유료 결제·외부 문의 발송·개인정보 조회·API 호출·앱 테스트는 수행하지 않음.
- 새 문서의 UTF-8, 제목과 공백 검사를 종료 전 수행하고 결과를 도구 출력에서 확인한다.
